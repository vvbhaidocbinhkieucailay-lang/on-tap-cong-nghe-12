# 🧪 Thư mục thử nghiệm — Sinh học 10 v2

Đây là **bản thử nghiệm** của hệ thống ôn tập/chấm điểm Sinh học 10 (v2),
dùng để giáo viên kiểm tra trước khi triển khai chính thức.

- Trang chính thức của học sinh nằm ở `../sinh-10/` — **không thay đổi**.
- File `index.html` ở đây KHÔNG chứa ngân hàng câu hỏi, đáp án hay lời giải.
- `APPS_SCRIPT_URL` đang để trống — giáo viên dán URL `/exec` của
  **Apps Script thử nghiệm** vào sau khi triển khai Web App thử nghiệm.
- Tuyệt đối không đưa file Excel đáp án, Script Properties hay khóa quản trị lên đây.
